# Music Career Simulator

Un simulateur de carrière musicale en français. Créez un artiste, développez sa carrière et prenez les décisions qui façonneront son parcours dans l'industrie musicale.

## Objectif

Construire progressivement un jeu de gestion musical riche : création d'artiste, écriture et production, sorties, promotion, streaming, classements, récompenses, tournées, merchandising et événements de l'industrie.

## Principes

- Interface et contenu du jeu en français.
- Simulation fictive et autonome : aucune dépendance aux classements ou plateformes réels.
- Moteur de simulation séparé de l'interface.
- Sauvegarde locale et tests des mécaniques importantes.

## Stack prévue

- React + TypeScript
- Vite
- Tailwind CSS
- IndexedDB pour les sauvegardes
- Vitest pour les tests

## Développement

Le projet démarre par un premier socle jouable : création d'une partie, tableau de bord, progression hebdomadaire et sauvegarde locale. Les systèmes de carrière seront ajoutés par étapes.

## Lancer le projet

Les instructions d'installation seront ajoutées avec le premier socle applicatif.
